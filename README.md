# AI-Powered Phishing URL Detection System

A cybersecurity project that detects malicious and suspicious websites using URL analysis, threat intelligence techniques, and Machine Learning concepts through an interactive web dashboard.

---

# Project Overview

The AI-Powered Phishing URL Detection System is designed to identify phishing websites by analyzing suspicious URL patterns, security indicators, and domain characteristics.

The system classifies URLs as:
- SAFE
- SUSPICIOUS
- PHISHING

This project demonstrates practical cybersecurity concepts used in:
- Threat Intelligence
- Website Security Analysis
- Phishing Detection
- Security Automation
- Machine Learning in Cybersecurity

---

# Features

## URL Threat Detection
- Detects phishing websites
- Identifies suspicious URL patterns
- Analyzes malicious domain indicators
- Performs threat classification

## Interactive Dashboard
- Real-time URL scanning

# Installation

## Clone Repository

```bash

```

## Navigate to Project Folder

```bash
cd phishing-url-detector
```

## Install Requirements


# Detection Techniques

The system analyzes:
- URL length
- HTTPS usage
- Presence of IP addresses
- Suspicious keywords
- Multiple subdomains
- Special characters
- Redirect patterns
